# ZeitBlick – APK-Downloads

Signierte Android-App für Termine, Geburtstage und gemeinsame Kalender.

**[Aktuelle Version herunterladen](https://github.com/YvesBerlin1990/ZeitBlick-Releases/releases/latest)**

## Installieren und aktualisieren

1. Auf der Release-Seite die Datei `ZeitBlick_v…_build…-release.apk` herunterladen und auf dem Android-Gerät öffnen.
2. Falls Android nachfragt, die Installation aus dieser Quelle erlauben und bestätigen.
3. Ab Version 1.0.6 unter **Einstellungen → Über ZeitBlick → App-Updates** nach weiteren Versionen suchen, herunterladen und installieren.

Ein GitHub-Konto oder Token ist nicht erforderlich. Beim ersten Wechsel auf den öffentlichen Downloadkanal Version 1.0.6 einmal manuell installieren. Die App entfernt zuvor gespeicherte Update-Zugangsdaten automatisch.

Direkte Updates erhalten die App-Daten, wenn die vorhandene App mit demselben Release-Schlüssel signiert ist. Eine frühere Debug-Installation kann eine andere Signatur haben; die vorhandene App bei einer Signaturfehlermeldung zunächst behalten.

## Inhalt dieses Repositorys

Hier liegen die Download-Anleitung und veröffentlichte APK-Dateien samt `SHA256SUMS.txt`. Der App-Quellcode und seine Git-Historie bleiben privat. Die automatisch erzeugten Dateien „Source code“ enthalten ausschließlich diese öffentliche Anleitung.

Die App prüft beim Download Dateigröße, SHA-256-Prüfsumme, Paket, Version und Signatur. Android bestätigt die Installation. Mindestversion: Android 8.0.
